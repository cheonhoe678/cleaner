엑셀 정리기, 쉽게 설명해요

초등학생에게 말하듯 풀어 쓴 설명서입니다. 뒤쪽에는 "규칙 파일(JSON)"을 직접 쓰는 방법이 있어요.

1. 이 도구는 뭐 하는 거예요?

선생님이 반 친구들 알림장을 걷었다고 생각해 보세요.

어떤 친구는 "전화"라고 쓰고, 어떤 친구는 "유선"이라고 썼어요. 같은 뜻인데 글자가 달라서 세기가 힘들죠. 어떤 친구는 아예 빈칸으로 냈고, 어떤 친구는 똑같은 걸 두 번 냈어요.

이 도구는 "청소 도우미 로봇"이에요. 엑셀 파일을 주면 이렇게 해요.

  1. 먼저 어디가 지저분한지 찾아서 알려줘요. (진단)
  2. 그다음 사람이 정해 준 규칙대로만 청소해요. (정리)
  3. 무엇을 바꿨는지 한 줄씩 적어 둬요. (변경 기록)
제일 중요한 약속 로봇은 스스로 판단하지 않아요. "유선은 전화로 바꿔라"처럼 사람이 적어 준 대로만 움직여요. 그 적어 준 종이가 바로 rules 폴더의 JSON 파일이에요.

2. 파일을 끌어다 놓으면 무슨 일이 생겨요?

택배가 분류센터를 지나가는 것과 같아요.

1
파일을 받아요 app.js — "택배 접수 창구". 끌어다 놓은 파일을 받아요.
2
내용을 읽어요 lib/xlsx.full.min.js — "번역가". 엑셀·CSV를 로봇이 읽을 수 있는 표로 바꿔요.
3
어디가 지저분한지 살펴봐요 clean.js의 진단 — "건강검진". 빈칸, 튀는 숫자, 섞인 날짜 모양, 똑같은 줄을 찾아요.
4
규칙 종이를 찾아와요 rules/파일이름.json — "청소 설명서". 파일 이름이 같은 설명서를 찾아요. 없으면 청소를 못 해요.
5
"규칙대로 정리" 버튼을 누르면 청소해요 clean.js의 적용 — "청소 로봇". 설명서에 적힌 순서대로 하나씩 고쳐요.
6
두 번 돌려 봐요 "청소한 방을 또 청소해도 똑같은가?" 확인해요. 달라지면 규칙이 이상한 거예요.
7
내려받아요 정리본과 변경 기록, 두 개의 CSV 파일을 받아요.
내 파일은 어디로 가나요? 아무 데도 안 가요. 모든 일이 내 컴퓨터의 브라우저 안에서 일어나요. 인터넷으로 읽어오는 건 "규칙 종이"와 "예시 파일"뿐이고, 내 파일을 올려 보내는 코드는 없어요.

3. JSON이 뭐예요?

JSON은 이름표 붙은 서랍장처럼 정보를 적는 약속된 글쓰기 방법이에요.

컴퓨터는 사람 말을 못 알아들어요. 그래서 "여기 이름표, 그 안에 내용"이라는 정해진 모양으로 써야 해요.

{
  "이름": "민수",
  "나이": 10,
  "좋아하는 것": ["축구", "게임"]
}
생김새뜻예
{ }서랍장 하나 (이름표: 내용 묶음){"a": 1}
[ ]줄 세운 목록["전화", "앱"]
"글자"글자는 꼭 큰따옴표로 감싸요"수료"
123숫자는 따옴표 없이180
true / false켜기 / 끄기"trim": true
자주 하는 실수 4가지 — 하나라도 틀리면 "규칙 파일을 읽지 못했습니다"가 떠요
  • ✕ 작은따옴표 '전화' → ○ 큰따옴표 "전화"
  • ✕ 마지막 항목 뒤에 쉼표 "a": 1, } → ○ 마지막에는 쉼표 없음
  • ✕ 메모(// 설명) 쓰기 → JSON에는 메모가 없어요. 설명은 "why"에 적어요
  • ✕ 중괄호·대괄호 닫는 걸 깜빡함

4. 규칙 파일은 어떻게 생겼어요?

규칙 파일은 "청소 설명서"예요. 큰 칸이 다섯 개 있어요.

칸 이름역할꼭 필요?
title설명서 제목. 화면 위쪽에 보여요사실상 필요 (없으면 "undefined"라고 떠요)
owner"누가 정한 규칙인지" 한마디. 제목 옆에 보여요사실상 필요
columns열(세로 칸)마다 어떻게 고칠지청소하려면 필요
cross_checks두 열을 같이 봐야 보이는 이상한 줄 찾기선택
duplicates똑같은 줄을 어떻게 할지선택
answer"정답 파일"과 비교할 때 쓰는 설정선택 (정답 대조를 쓸 때만)
order_note"이 순서로 하는 이유" 설명. 화면에 보여요선택
파일 이름이 중요해요 상담이력.xlsx 파일을 넣으면 rules/상담이력.json을 찾아요. 이름이 하나라도 다르면 못 찾아요. (이름이 달라도 화면의 "내 규칙 파일 불러오기" 버튼으로 직접 고를 수 있어요.)

5. columns — 열마다 청소법 적기

columns 안에 엑셀의 열 이름을 적고, 그 안에 "어떻게 고칠지"를 적어요. 열 이름은 엑셀 맨 윗줄 글자와 똑같이 써야 해요. 없는 열 이름이면 조용히 건너뛰어요.

"columns": {
  "채널": {                          ← 엑셀의 "채널" 열
    "trim": true,                      ← 앞뒤 빈칸 지우기
    "map": { "유선": "전화" },       ← "유선"을 "전화"로 바꾸기
    "why": "같은 채널을 여러 이름으로 적었다"
  }
}

쓸 수 있는 도구 상자

도구뜻 (쉽게)이렇게 써요
trim글자 앞뒤의 쓸데없는 빈칸 털기"trim": true
map"이 글자는 저 글자로 바꿔" 변환표{"유선": "전화", "app": "앱"}
blank_to빈칸이면 이 값으로 채우기"blank_to": "N"
strip_units숫자 뒤에 붙은 단위 떼기["개", "원"] ("3개" → "3")
number숫자처럼 생긴 글자를 진짜 숫자로"number": true
date날짜 모양을 2025-03-14 하나로"date": true
rescale너무 큰 숫자는 단위가 다른 것으로 보고 나누기{"over": 180, "divide": 60}
missing빈칸인 줄에 깃발 꽂기 (지우거나 채우지는 않음)"missing": "flag"
range범위를 벗어난 숫자에 깃발 꽂기{"min": 0, "max": 400, "action": "flag"}
why"왜 이렇게 정했는지" 이유. 로봇은 안 읽고 사람이 읽어요. 변경 기록에도 남아요"why": "…"

실제 예: 이렇게 바뀌어요

채널 (전)유선 · 전화상담 · chatbot · APP · e-mail
채널 (후)전화 · 전화 · 챗봇 · 앱 · 이메일
상담시간 (전)25 · 31 · 1800 · 2400
상담시간 (후)25 · 31 · 30 · 40 (180 넘는 건 ÷60)
과정수 (전)3개 · 5 · 2개
과정수 (후)3 · 5 · 2
순서가 있어요 (한 열 안에서) 로봇은 항상 이 순서로 해요: trim → map → blank_to → strip_units → number → date → rescale → missing / range
그래서 "앞뒤 빈칸을 먼저 털고, 그다음에 변환표를 본다"고 생각하면 돼요. 예를 들어 " 유선 "은 trim으로 "유선"이 된 다음에야 map에서 "전화"로 바뀌어요.
알아 두면 좋은 함정
  • map은 글자가 정확히 같을 때만 바뀌어요. "APP"와 "app"는 서로 달라서 둘 다 적어야 해요.
  • missing과 range의 action은 지금 "flag"만 동작해요. 다른 값을 쓰면 아무 일도 안 일어나요.
  • range는 숫자가 된 값만 검사해요. 그래서 같은 칸에 "number": true도 같이 써 두는 게 좋아요.
  • rescale도 숫자에만 통해요. 역시 number와 함께 써요.
  • 깃발(flag)은 줄을 지우지 않고, 결과의 _표시 열에 이유를 적어 줘요.

6. cross_checks — 두 열을 같이 봐야 보이는 거짓말

시험지에서 "점수 0점"인데 "합격"이라고 적혀 있으면 이상하죠? 점수만 봐도, 합격만 봐도 멀쩡해 보여요. 둘을 같이 봐야 이상한 걸 알 수 있어요.

이럴 때 cross_checks를 써요. 줄을 지우지 않고 깃발만 꽂아서 사람이 다시 확인하게 해요.

"cross_checks": [
  {
    "label": "이수 0시간인데 수료",          ← 깃발에 적힐 글자
    "when": [                                  ← 아래 조건이 "전부" 맞을 때
      ["이수시간", "==", 0],
      ["수료여부", "==", "수료"]
    ],
    "why": "두 열을 같이 봐야 드러난다"
  }
]

조건 한 줄은 [열 이름, 비교 방법, 값] 세 칸이에요.

비교 방법뜻예
"=="같다["수료여부", "==", "수료"]
"!="다르다["채널", "!=", "전화"]
">" / "<"크다 / 작다 (숫자)["상담시간", ">", 100]
"blank"비어 있다["이수시간", "blank"]
두 가지 약속
  • when 안의 조건은 전부 맞아야(그리고) 깃발이 꽂혀요. "또는"은 없어요.
  • 값에 숫자(0)를 쓰면 숫자로, 글자("수료")를 쓰면 글자로 비교해요.
  • 빈칸은 0이 아니에요. 빈칸인 줄은 "==", "<" 같은 비교에서 조용히 빠져요. (없는 사실을 만들지 않으려고요.)

7. duplicates — 똑같은 줄 한 번만 남기기

"duplicates": {
  "action": "drop",                       ← 지금은 "drop"(하나만 남기고 지움)만 동작
  "why": "모든 열이 같은 행은 하나만 남긴다"
}

모든 열이 완전히 같을 때만 같은 줄로 봐요. 한 칸이라도 다르면(예: 접수일이 다르면) 다른 줄이라 남겨요. 중복 검사는 맨 마지막에 해요. 그래서 날짜 모양을 먼저 맞춘 뒤에야 "사실은 같은 줄"이 드러나요.

8. answer — 정답 파일과 비교하고 싶을 때 (선택)

"answer": {
  "key": ["상담ID", "접수일"],             ← 같은 줄을 찾는 "주민번호" 열들
  "compare": ["채널", "재문의", "상담시간"],   ← 값이 같은지 비교할 열들
  "note": "정답은 완성 기준이 아니다"
}

정답은 "만점 기준"이 아니라 "내 규칙이 뭘 놓쳤나"를 비춰 보는 거울이에요.

9. 처음부터 내 규칙 파일 만들기

"수강신청.xlsx"라는 파일에 학년(1·2·3), 결제금액("12,000원"처럼 단위 섞임), 상태("완료/끝/Done" 섞임)가 있다고 해 볼게요.

  1. 파일 이름을 rules/수강신청.json으로 만들어요.
  2. 아래를 복사해서 열 이름과 규칙을 내 파일에 맞게 바꿔요.
  3. 엑셀 파일을 끌어다 놓고 "규칙대로 정리"를 눌러요.
  4. 결과의 "두 번 돌려도 같은 결과"가 ✓로 나오는지, 변경 기록이 말이 되는지 눈으로 봐요.
{
  "title": "수강신청 처리 규칙",
  "owner": "사람이 정한 규칙입니다. 도구는 이대로 할 뿐입니다.",
  "order_note": "표기를 먼저 맞춘 뒤 두 열을 같이 봅니다.",

  "columns": {
    "결제금액": {
      "strip_units": ["원"],
      "number": true,
      "missing": "flag",
      "why": "'12,000원' 같은 글자를 숫자로. 빈칸은 채우지 않고 표시만"
    },
    "상태": {
      "trim": true,
      "map": { "끝": "완료", "Done": "완료" },
      "why": "같은 뜻을 '완료' 하나로"
    }
  },

  "cross_checks": [
    {
      "label": "0원인데 완료",
      "when": [ ["결제금액", "==", 0], ["상태", "==", "완료"] ],
      "why": "지우지 않고 표시해서 사람이 확인"
    }
  ],

  "duplicates": { "action": "drop", "why": "모든 열이 같은 행은 하나만" }
}
규칙을 쓰는 요령 3가지
  • 이유(why)를 꼭 적어요. 한 달 뒤의 내가 "왜 이렇게 했지?" 하고 물을 때 답이 돼요.
  • 모르는 건 채우지 말고 깃발만 꽂아요. 빈칸을 추측해서 채우면 없던 사실이 생겨요.
  • 값 목록을 눈으로 봐요. "완료"와 "수료"가 같은 뜻인지는 로봇이 몰라요. 사람이 보고 map에 적어야 해요.

10. 한눈에 정리

  • 로봇(clean.js)은 규칙 종이대로만 움직여요. 스스로 판단하지 않아요.
  • 규칙 종이(rules/*.json)는 사람이 써요. 이유(why)까지 같이 적어요.
  • 내 파일은 브라우저 밖으로 나가지 않아요.
  • 로봇이 못 보는 것: 뜻이 같은 다른 말, 색깔로만 한 표시, 병합된 칸, 여러 시트. 이건 사람이 눈으로 봐야 해요.
